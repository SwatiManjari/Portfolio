# Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my skills, projects, education, and web development journey.

## Overview

This portfolio is a collection of my web development work and a place to experiment with different frontend concepts. It includes interactive sections, responsive layouts, theme switching, and projects built while learning JavaScript.

## Features

- Responsive navigation with a mobile menu
- About Me section
- Skills section
- Projects showcase
- Open source contributions section
- Education section
- Contact form with validation that opens your email app with the message filled in
- Light/Dark theme toggle that remembers your choice and follows the system setting by default
- Navigation highlights the section you are reading
- Responsive design from small phones to desktop
- Keyboard and screen reader friendly

## Getting Started

To run the portfolio locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser, or start a local server with `python3 -m http.server 5500` and visit http://localhost:5500.

No additional dependencies are required.
